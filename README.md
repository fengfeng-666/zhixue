# 知学 · 多模态智能学习助手

面向高校学习场景的可运行原型：管理个人课程和资料，检索资料进行多轮问答、知识讲解、错题复盘、学习规划和测验生成。

## 启动

需要 Docker Compose 和兼容 OpenAI 接口、支持工具调用、图片理解及 embedding 的模型服务。模型配置可在登录后的「模型设置」中填写并保存，也可通过环境变量设置服务端默认值。

```bash
cp .env.example .env
# 可选：编辑 .env 设置服务端默认模型；也可在页面中单独配置
docker compose up --build
```

打开 http://localhost:8000，注册登录后打开「模型设置」填写接口地址、API Key 和模型名称，创建课程并在知识库中上传图片或文档。API 文档在 http://localhost:8000/docs。停止服务使用 `docker compose down`；PostgreSQL 数据保存在 Docker volume 中。

## 功能与实现

- 每个账户可以单独配置接口地址、对话模型、视觉模型、向量模型和 API Key；密钥经 Fernet 加密后存储，读取设置时不会返回密钥明文。Docker 使用 app_data 卷保存加密密钥，本机直接运行默认使用项目的 data 目录；切换运行方式、备份或迁移时，需将对应的 `model-key` 与数据库一同保留。已有资料时，需先删除资料才能更换接口地址或向量模型。
- 每个账户独立管理课程、文档、会话、错题和学习偏好；密码采用 PBKDF2，登录令牌只保存哈希。课程相关查询校验归属。
- 支持 UTF-8 文本、Markdown、可提取文本的 PDF、DOCX、PPTX 和 PNG/JPEG/WebP。图片通过视觉模型识别；文档提取文本后切分、向量化并存入 PostgreSQL/pgvector。单文件上限 10 MB、200 个片段。扫描版 PDF、文档中嵌入的图片和公式图片暂未自动识别，可先导出为图片上传。
- 向量精确检索和中文字符二元组关键词召回，经倒数排名融合排序（资料规模较大时需进一步优化检索性能）；回答可引用资料名和片段编号。模型依据会话上下文生成独立检索问题，跨会话检索同课程历史与错题。
- LangGraph 使用模型工具调用执行 ReAct 循环：选择资料检索或历史检索工具、观察结果、继续推理；PostgreSQL 检查点持久化图状态。模型调用具备有限自动重试。失败时可在界面重新提交；完整的中断后从失败节点恢复和并发会话控制尚未实现。
- Redis 缓存近期会话消息；PostgreSQL 是会话和用户数据的持久化来源。测验目前由模型生成并展示答案解析，尚无自动评分或独立题库。

## 注意事项

这是开发原型，默认数据库凭据和端口仅适合本地使用。部署到公网前需要配置 HTTPS、限流、文件内容校验、密钥管理及更严格的会话安全策略。上传文本和图片会发送给配置的模型服务；请确保有权处理这些数据。支持 1～16000 维的 embedding；同一账号的资料须使用相同维度，更换 embedding 模型时需重新导入资料；修改已有文档需先删除再上传。模型产生的答案和计划需要人工核验。

## 测试

```bash
python -m unittest discover -s tests
```

核心逻辑测试不需要数据库或模型服务；完整联调需要运行上述服务并配置模型密钥。
